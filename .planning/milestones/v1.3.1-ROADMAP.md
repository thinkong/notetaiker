## Milestone Summary

**Decimal Phases:**
None.

**Key Decisions:**

- **Enable verbatimModuleSyntax in base TSConfig**: Ensures exact module handling and better tree-shaking across the monorepo.
- **Enforce type-only imports**: prevents accidental side-effect imports and runtime overhead.
- **Manual tags priority**: Manual tags are shown before AI tags in the UI to respect user intent.

**Issues Resolved:**

- Unified the Tag component usage across the app.
- Implemented tag removal workflow (missing in v1.3).
- Fixed build system fragility regarding type imports.

**Issues Deferred:**

None.

**Technical Debt Incurred:**

- **AI Tag Regeneration**: Removed AI tags are not explicitly added to an `ignored_tags` list, so they might reappear if the AI re-processes the note. Accepted for this patch release.
