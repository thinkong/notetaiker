# Milestone v1.3: UX Polish & Flow

**Status:** ✅ SHIPPED 2026-01-31
**Phases:** 12-13
**Total Plans:** 7

## Overview

**Goal:** Improve user experience with better navigation, manual controls, and smoother editing flow.

**Target features:**
- Click note in side panel to open in editor
- "Save" ends the current edit session (ready for next)
- Auto-clear default placeholder on focus
- Manual tag entry support during capture

## Phases

### Phase 12: UX Flow Improvements

**Goal**: Seamless navigation and editing session management
**Depends on**: Phase 11
**Plans**: 4 plans

Plans:
- [x] 12-01-PLAN.md — Foundation hooks and UI components (draft persistence, unsaved changes, toast, confirm dialog)
- [x] 12-02-PLAN.md — Note preview overlay and editor focus control
- [x] 12-03-PLAN.md — Save-and-reset flow integration with draft management

**Success Criteria** (what must be TRUE):

  4. Navigation between notes feels instant and intentional (no accidental state preservation)

### Phase 13: Manual Tag Control

**Goal**: User control over tags with intelligent AI preservation
**Depends on**: Phase 12
**Plans**: 3 plans

Plans:
- [x] 13-01-PLAN.md — Schema and API Updates
- [x] 13-02-PLAN.md — Editor Enhancements (Hashtags)

**Details:**
**Success Criteria** (what must be TRUE):

  4. User can inspect note frontmatter and identify which tags came from AI vs manual input

## Milestone Summary

**Key Decisions:**

- **Guard-First Navigation**: All state-changing navigation (preview, edit, home) passes through a central requestAction guard to prevent data loss.
- **Schema Separation**: AI suggestions are stored in `ai_tags` while user tags remain in `tags` to prevent overwriting user intent.
- **Tag Visuals**: Manual tags are Blue (Nord Frost 3), AI tags are Purple (Nord Aurora 4) for clear distinction.
- **Atomic Session Workflow**: Save action clears state, persists to permanent storage, and resets the interface for the next capture automatically.

**Issues Resolved:**

- Fixed broken routing tests in Phase 13-01.
- Fixed click propagation issues in sidebar components.
- Integrated draft persistence to prevent data loss on refresh.

**Technical Debt Incurred:**

- **NotePreviewOverlay**: Uses raw tag implementation instead of shared `Tag` component (minor visual inconsistency).
- **Graph View**: Uses aggregated tags, distinction between manual/AI is purely visual in the node list but unified in the graph structure.
