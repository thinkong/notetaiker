**Status:** ✅ SHIPPED 2026-01-30

## Overview

Milestone v1.2 focuses on visual exploration of notes via a force-directed graph based on tags and links.

## Phases

### Phase 11: Graph View

**Goal**: Visual exploration of notes via a force-directed graph based on tags and links.
**Depends on**: Phase 10
**Plans**: 3 plans

Plans:

- [x] 11-01: Setup Infrastructure and Data Transformation
- [x] 11-02: Core Graph Visualization
- [x] 11-03: Note Side Panel and Navigation

**Details:**
- **Graph Visualization**: Used `react-force-graph-2d` for performance and Canvas rendering for scalability.
- **Tag Hub Structure**: Implemented a "Tag Hub" structure where notes link to shared tag nodes, creating clusters.
- **Side Panel**: Used an absolute-positioned side panel to avoid reflowing the graph canvas on every click.
- **Navigation**: Integrated the existing Markdown component to ensure visual consistency with the timeline view.

## Milestone Summary

**Key Decisions:**
- Decision: Use Canvas rendering for graph (Rationale: Scalability for 1000+ notes)
- Decision: Tag Hub architecture (Rationale: Better clustering of related notes)
- Decision: Side Panel for details (Rationale: Maintain graph context while reading)
