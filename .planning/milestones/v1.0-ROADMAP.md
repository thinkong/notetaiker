## Milestone Summary

**Key Decisions:**

- **Local Server Architecture**: Enables background processing, file system access, and future CLI/Desktop clients connecting to same core.
- **Atomic Notes**: Reduces friction (no naming required) and fits "stream of thought" model better than daily notes.
- **YAML Frontmatter**: Standard, portable way to attach metadata without polluting body content.
- **Web Client First**: Fastest path to validation; PWA capabilities can mimic desktop feel.
- **Local Mirror Pattern**: Store full note content in SQLite index for <5ms listing performance.
- **Separate Index DB**: Placed metadata index in its own database (index.db) to decouple from the task queue.
- **Immediate-feedback-save**: Bypass debounce for Cmd+Enter to ensure user data safety.

**Issues Resolved:**

- Implemented core capture flow (latency < 100ms).
- Established atomic file storage compatible with Obsidian/other tools.
- Integrated background AI processing queue.
- Delivered real-time updates via SSE.
- Implemented fuzzy search and keyboard navigation.
