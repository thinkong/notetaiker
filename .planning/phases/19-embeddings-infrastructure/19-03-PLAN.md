# Phase 19-03: Management & UI

## Goal

Provide user controls to manage the embedding index.

## Context

Users may need to rebuild the index if they change models or if something gets out of sync.

## Changes

### 1. Bulk Operations

- **File:** `apps/api/src/services/embeddings.service.ts`
- **Action:** Add `rebuildIndex()` method.
  - Truncate `embeddings` tables.
  - Iterate all notes in `storage.service`.
  - Enqueue embedding jobs for each.

### 2. API Endpoint

- **File:** `apps/api/src/index.ts` (or relevant router)
- **Action:**
  - `POST /api/embeddings/rebuild`
  - `GET /api/embeddings/status` (count of indexed notes vs total notes)

### 3. Frontend Settings

- **File:** `apps/web/src/components/settings/SettingsPage.tsx`
- **Action:**
  - Add "Smart Connections" section.
  - Show "Indexed Notes: X / Y".
  - Add "Rebuild Index" button.
  - Add loading state while rebuilding (though it's async, just show "Rebuild started").

## Verification

- Click "Rebuild Index".
- Watch server logs for batch processing.
- Verify status count increases.
