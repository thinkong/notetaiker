  <files>apps/api/src/services/indexer.service.ts</files>
  <action>
    Create a new `IndexerService` that manages a `notes_index` table in the existing SQLite database (reuse `queue.db` or create `notetaiker.db`).
    The table should store: `id` (PK), `filename`, `tags` (JSON string or comma-separated), `createdAt`, `updatedAt`, and `contentHash` (optional but recommended for sync optimization).
    Implement:
    - `syncAll()`: Scans the notes directory and upserts missing/changed notes.
    - `syncNote(filePath, content, metadata)`: Upserts a single note's metadata.
    - `deleteNote(id)`: Removes a note from the index.
    - `query(options)`: Provides fast filtering and sorting (by tags, date).
  </action>
  <verify>
    Run a standalone script or test to verify that `syncAll` populates the database and `query` returns the expected records.
  </verify>
