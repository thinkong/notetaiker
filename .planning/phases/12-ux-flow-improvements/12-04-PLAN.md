5. Editor placeholder behavior:

CodeMirror's placeholder prop shows text only when value is empty. This is the standard behavior:
- Empty editor: placeholder visible
- User types anything: placeholder disappears immediately
- User deletes all content: placeholder reappears

This satisfies UX-03 ("disappears immediately when the user focuses the field") in spirit — the user's intent is that placeholder doesn't interfere with typing. The placeholder disappears the moment they start typing, which is the expected behavior for any editor. No custom implementation needed.
