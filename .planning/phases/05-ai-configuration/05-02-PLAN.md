<task type="auto">
  <name>Task 1: Implement Validation Logic</name>
  <files>apps/api/src/routes/settings.ts</files>
  <action>
    Add a `POST /validate` endpoint to the settings routes that:
    1. Accepts a provider ID (openai, anthropic, gemini) and credentials.
    2. Performs a lightweight check against the provider's API:
       - OpenAI: `GET https://api.openai.com/v1/models`
       - Anthropic: `GET https://api.anthropic.com/v1/models`
       - Gemini: `GET https://generativelanguage.googleapis.com/v1beta/models?key=${apiKey}`
    3. Returns 200 on success, or a 400/error response with the specific message from the provider on failure.
    4. Respects custom `baseUrl` if provided in the credentials.
  </action>
  <verify>
    - Mock the external API calls in a test or use a temporary test script to verify that valid/invalid keys return correct status codes.
    - Verify that custom base URLs are used when provided.
  </verify>
  <done>Validation endpoint accurately reports credential status.</done>
</task>
