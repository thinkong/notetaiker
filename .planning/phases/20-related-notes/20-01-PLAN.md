<task type="auto">
  <name>Implement Related Notes Endpoint</name>
  <files>apps/api/src/routes/notes.ts</files>
  <action>
    1. Add `.get("/:id/related", ...)` to the notes router.
    2. The handler should:
       - Get `noteId` from params.
       - Use `embeddingsService.getVector(noteId)` to get the current note's vector.
       - If not found, return an empty array (note not indexed yet).
       - Call `embeddingsService.findSimilar(vector, limit, noteId)` to find neighbors.
       - For each result, use `storageService.getNote(noteId)` to get the full metadata (titles, tags).
       - Return a JSON list of related notes with metadata and distance.
  </action>
  <verify>Run `curl http://localhost:3001/api/notes/{id}/related` and verify JSON response format.</verify>
  <done>Backend API returns related notes for a given ID.</done>
</task>
